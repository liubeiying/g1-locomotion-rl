# 环境搭建

> 上游：legged_gym / rsl_rl / unitree_rl_gym

## 安装顺序

顺序不能乱，Isaac Gym 必须先装，而且要先用它自带的 example 验证过再往下走。

1. **Isaac Gym**：跑通自带 example（如 `1080_balls_of_solitude.py`）
2. **rsl_rl**：PPO 实现，legged_gym 对它的版本很敏感
3. **legged_gym**：训练框架
4. **unitree_rl_gym**：G1 配置 + MuJoCo / 真机部署链路

我一开始跳过了第 1 步的验证直接往后装，结果后面报错时分不清是环境问题还是代码问题，又倒回来重查，多花了半天。**这一步没过就别往下装。**
